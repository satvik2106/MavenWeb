2️⃣ Create DynamoDB Table
Open Amazon DynamoDB

✅ Stores file metadata from S3 events.

3️⃣ Create IAM Role for Lambda
Go to AWS Identity and Access Management
Create Role → Select Lambda

Attach policies:

AmazonS3FullAccess
AmazonDynamoDBFullAccess
AWSLambdaBasicExecutionRole

⚠️ Better Practice (Important):
Instead of full access, use least privilege:

S3: GetObject
DynamoDB: PutItem
4️⃣ Create Lambda Function
Open AWS Lambda
Create function:
Name: S3DynamoLambda
Runtime: Python 3.x
Role: LambdaS3DynamoRole
5️⃣ Add Python Code
import boto3
from uuid import uuid4

def lambda_handler(event, context):
    dynamodb = boto3.resource('dynamodb')
    table = dynamodb.Table('newtable')

    for record in event['Records']:
        bucket_name = record['s3']['bucket']['name']
        object_key = record['s3']['object']['key']
        size = record['s3']['object'].get('size', -1)
        event_name = record['eventName']
        event_time = record['eventTime']

        table.put_item(
            Item={
                'unique': str(uuid4()),
                'Bucket': bucket_name,
                'Object': object_key,
                'Size': size,
                'Event': event_name,
                'EventTime': event_time
            }
        )

👉 Minor improvement: moved table = dynamodb.Table(...) outside loop (more efficient)

Click Deploy
